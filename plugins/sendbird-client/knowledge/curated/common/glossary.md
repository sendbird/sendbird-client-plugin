# Sendbird — Glossary

## Overview
Plain definitions of common Sendbird terms. Conceptual only; no API signatures.

## Terms
- app_id: the Application ID that scopes all your Sendbird data.
- access token / session token: credentials used to authenticate a user connection. Issued by your backend; never hard-code them.
- group channel: a channel for a known set of members (1:1 or group).
- open channel: a channel anyone can enter (broadcast-style).
- operator: a user with moderation privileges in a channel.
- unread count: number of messages a user has not yet read.
- region: the hosting region for an application.
